# 04 — Templates FR

Règles d'or pour tous les messages :

1. **Court** — 3-5 phrases max pour les premiers messages.
2. **Personnalisé** — toujours un détail spécifique au prospect (signal de fit) dans les 2 premières phrases.
3. **Une seule CTA** — démo de 15 min via le calendrier.
4. **Pas de "j'espère que vous allez bien"** — direct au sujet.
5. **Pas de jargon** — pas de "synergies", "optimiser le funnel". Parler comme un humain.
6. **Tutoyer ou vouvoyer ?** → **Vouvoyer** par défaut sur email/LinkedIn (formel), **tutoyer** sur IG/TikTok (informel social). Adapter au vertical : vouvoyer pour pros (notaires, immo), tutoyer pour créatifs (salons, restos jeunes).

Placeholders entre `{{ }}`. L'agent remplit.

## Notes sur le placeholder `{{signal_specifique}}`

C'est **LA** ligne qui détermine si le message marche ou pas. Exemples concrets :

| Type de signal | Exemple |
|---|---|
| Avis Google | "j'ai lu les 3 derniers avis qui mentionnent l'attente au téléphone" |
| Post réseau social | "ton post de mardi sur le nouveau service" |
| Annonce / nouvelle | "votre récente expansion à Laval" |
| Site web | "j'ai vu que vous offrez maintenant la téléconsultation" |
| Vidéo TikTok | "ta vidéo sur les coupures dégradées qui a fait 12k vues" |
| Annonce Kijiji | "votre annonce pour une réceptionniste à temps partiel" |

**Règle** : si l'agent n'a pas de signal spécifique → **ne pas envoyer**. Score < 3.
Mieux vaut moins de prospects mais touchés correctement.
